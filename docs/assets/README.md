# Public launch assets

## GitHub / social preview

Use [`ai-memory-social-preview.svg`](ai-memory-social-preview.svg) as the source artwork for the repository social-preview card and launch posts.

For GitHub's repository **Social preview** setting, export the SVG to a 1280×640 PNG before upload if GitHub does not accept the SVG directly. Keep the wording and repository URL intact so previews remain understandable when shared outside GitHub.

This asset intentionally emphasizes the product problem and outcome before implementation details:

**saved content → vague remembered phrase → hybrid retrieval → correct source → cited answer**

Pair the card with the short product demo described in [`../LAUNCH_KIT.md`](../LAUNCH_KIT.md). The video/GIF should remain the primary launch asset; this card is the fallback for link previews and posts where video is unavailable.

No runtime code or user data is involved in these assets.
