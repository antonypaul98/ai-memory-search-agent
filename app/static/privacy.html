Privacy Policy

AI Memory Agent · Effective 2026-07-30 · Product version 1.x

AI Memory Agent helps you intentionally save web and YouTube knowledge into a personal Memory backend you control, then search and ask questions over that library.

Single purpose. Save and search personal learning content. The extension does not inject ads, mine browsing history in the background, or sell your data.

What we collect

  • URLs and page titles you explicitly save or import
  • Optional bookmark URLs/titles you choose to import
  • Optional YouTube metadata available at save time (title, channel, video id)
  • Account email and session token if you register when auth is enabled
  • Temporary observe context on your device only (session storage, ~30 minute TTL)

What we do not collect

  • Passwords, payment fields, or private form inputs
  • Keystrokes, screenshots, audio, or video recordings
  • Incognito activity (incognito is not enabled in V1)
  • Browsing history beyond the active tab at the moment you save

Where data lives

Saved memories are stored on the backend you configure (typically self-hosted FastAPI with SQLite + ChromaDB). Extension temporary context stays in Chrome session storage and is not synced to the cloud by the extension.

How data is used

Data is used only to provide save, search, chat-with-citations, import, and related Memory features. Optional LLM providers receive retrieved chunks when chat is enabled; you can disable LLM by setting llm_provider=none.

Sharing

We do not sell personal data. Data may be sent to YouTube (or other source APIs) during ingest you initiate, and to an optional LLM provider you configure. The extension developer does not receive your Memory contents from a self-hosted backend.

Your controls

  • Pause observation / clear temporary context in the extension popup
  • Delete individual memories via DELETE /api/v1/memories/{id} or the Workspace
  • Export your data as JSON via GET /api/v1/privacy/export
  • Delete all memories via DELETE /api/v1/privacy/memories
  • Log out / revoke session when auth is enabled
  • Remove the extension in Chrome settings at any time

Chrome Web Store disclosure (summary)

Permissions are limited to storage, active tab access on user action, optional bookmarks import, optional notifications, and host access to your configured API. See store disclosure text and docs/V1_PRIVACY_MODEL.md in the project repository.

Contact

For privacy requests on a self-hosted instance, contact the operator of that instance. Rotate AUTH_SECRET and revoke sessions if a credential is compromised.
